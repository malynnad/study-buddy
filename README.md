# Study-buddy

一个可以自己运行在电脑上的小学五年级练习应用：**AI 按教材章节出题 → 屏幕作答 → 自动批改 → 错题自动收录 → 按薄弱知识点分析 → 再出题巩固**，并统计每次出题消耗的 token 与预估费用。

面向深圳小学五年级，覆盖**数学、语文、英语、科学**四科。整个项目零依赖、无构建步骤，下载后双击即可使用。

---

## 三步开始使用

1. **安装 Node.js 22 或更高版本**：<https://nodejs.org/>（选择 LTS 版本即可）。
2. **下载代码**（二选一）：

```bash
git clone https://gitee.com/dannylam/study-buddy.git      # Gitee（国内更快）
git clone https://github.com/malynnad/study-buddy.git     # GitHub
```

   也可以在仓库页面点「克隆/下载」→ 下载 ZIP 后解压。

3. **启动**：
   - macOS：双击根目录的 `启动.command`
   - Windows：双击根目录的 `启动.bat`
   - 或者命令行执行 `node server.js`

浏览器会自动打开 <http://localhost:3000>。关闭终端窗口即停止服务。

> macOS 首次运行若提示无法打开，在终端执行一次 `chmod +x 启动.command`，或右键点击该文件选择「打开」。

### 配置大模型（可选但推荐）

没有 API Key 也能用，但只有数学有内置示例题库兜底；语文、英语、科学需要配置 Key 才能出题。

打开页面右上角「设置」，填写：

| 配置项 | 示例值 |
| --- | --- |
| 接口地址 | `https://api.deepseek.com` |
| 模型 | `deepseek-flash` |
| API Key | 以 `sk-` 开头的 Key |

也支持其它 OpenAI 兼容服务（通义千问、智谱 GLM、Kimi、OpenAI），设置页有预设可一键套用。保存后点「测试连接」验证。

Key 只保存在本机的 `data/config.json`，不会随代码提交到仓库。

## 功能

- **按章节出题**：先在页面上选择学科与学期，再点选要练的单元（整章选中），题量可选 10 / 20 / 30 / 40 / 50。题量较大时自动按 10 题一批并行生成，缩短等待。
- **多种题型**：选择题、填空题、计算题、应用题，数学还支持**方格纸作图题**（补全轴对称图形、平移后图形、指定面积的图形），在网页上点格点即可作答，系统按几何性质自动判分。
- **自动判分**：数值容差、分数/带分数/小数等价、英文大小写不敏感；作图题按对称、平移、面积等几何不变量判定，并给出具体错因。
- **错题本**：答错自动收录，可标记掌握、按学科筛选、一键再练，作图题可回看作答图形与标准图形。
- **学情分析**：按知识点正确率生成薄弱点画像与学习建议，可针对薄弱点再出巩固题。
- **用量与费用**：每次出题、每次分析都显示输入/输出 tokens 与预估金额，设置页可查看累计用量和分学科统计。

## 环境要求

- Node.js **22 或更高版本**（使用了内置的 `node:sqlite`，已在 Node 26 验证）
- 无需安装任何 npm 依赖，无需构建
- 操作系统：macOS / Windows / Linux

## 数据与隐私

运行时会在项目根目录创建 `data/`：

- `data/app.db`：练习记录、错题、用量统计
- `data/config.json`：模型配置与 API Key
- `data/system-ca.pem`：系统证书缓存

`data/` 已在 `.gitignore` 中排除，不会上传。练习数据只存在本机，删除该目录即可清空全部记录。

## 计费说明

单价定义在 `server/pricing.js`，单位为「元 / 百万 tokens」，按 DeepSeek 官方公示价估算：

| 模型 | 时段 | 输入（缓存未命中） | 输入（缓存命中） | 输出 |
| --- | --- | --- | --- | --- |
| deepseek-flash | 高峰 | 2 | 0.04 | 8 |
| deepseek-flash | 空闲（5 折） | 1 | 0.02 | 4 |
| deepseek-v4-pro | 高峰 | 9 | 0.30 | 27 |
| deepseek-v4-pro | 空闲（5 折） | 4.5 | 0.15 | 13.5 |

高峰时段为北京时间周一至周五 9:00–12:00、14:00–18:00（不含法定节假日）；其余时段（含周末、节假日）为空闲时段。页面显示的是估算参考金额，实际扣费以服务商账单为准。

## 常见问题

- **端口被占用**：默认使用 3000，可先关闭占用该端口的程序，或临时指定端口 `PORT=3001 node server.js`。
- **macOS 提示无法验证开发者**：右键点击 `启动.command`，选择「打开」。
- **Windows 提示未安装 Node.js**：安装 22 以上版本后重新打开 `启动.bat`。
- **连接模型失败**：检查网络或代理；程序会自动合并系统证书链，代理环境仍失败时可尝试关闭代理。
- **语文 / 英语 / 科学无法出题**：这三科必须配置可用 API Key，只有数学有无 Key 的示例题库兜底。
- **作图题看不到方格纸**：说明该题生成时缺少图形数据，重新出一轮即可；程序已丢弃“题干提到图却没有图形”的坏题并自动补题。
